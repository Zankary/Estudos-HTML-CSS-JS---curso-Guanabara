# Estudos de HTML, CSS e JavaScript — Curso Gustavo Guanabara

Repositório com os exercícios, anotações e o projeto prático que desenvolvi
durante meus estudos de HTML, CSS e JavaScript, seguindo as aulas do
Curso em Vídeo (Gustavo Guanabara).

## 📚 Sobre

Este material foi produzido como parte do meu aprendizado em front-end.
A proposta era entender a estrutura de uma página web, estilização com CSS
e pequenas interações com JavaScript, aplicando tudo em uma modificação
de site como projeto final.

O arquivo principal é o `index.html` — basta abri-lo no navegador para
visualizar o site e navegar pelos exemplos e exercícios.

## 🧠 O que foi estudado

- Estrutura básica de uma página HTML (tags, semântica, links, imagens)
- Estilização com CSS (cores, fontes, layout, box model)
- Noções iniciais de JavaScript (pequenas interações)
- Organização de arquivos de um site (HTML, CSS, JS, imagens)
- Modificação de um site existente como projeto prático
